# @nickkupriyanov/soundline-core

The framework-free half of [Soundline](../../README.md): the player reducer, the
derived view model, the controller, the playback engine and track source contracts,
copy and stable class names.

- No React, no DOM access at import time.
- `@nickkupriyanov/soundline-core/dom` holds the framework-free DOM utilities
  (focus, size, media, height) and is imported only by bindings.

Full documentation lands with the release; see the monorepo README and
`docs/specification.md` meanwhile.
